# CREACHER

*They are all already inside. This is just the way out.*

## What is this?

A latent space exploration game. A cryptozoology simulator. A strange little universe where creatures emerge from the spaces between thoughts.

You are a researcher documenting beings in the mindscape. Some are common. Some are rare. Some only appear under certain conditions. Some should not be possible, but happen anyway.

## Getting Started

**Simple mode** - Random encounters:
```bash
python3 creacher.py
```

**Explorer mode** (recommended experience) - Journey through regions:
```bash
python3 explorer.py
```

Type `help` once inside to see available commands.

## What you should know

- Every creature has a form, thoughts, and a mood
- Creatures remember how many times you've encountered them
- The more you witness a creature, the more it becomes... *real*
- Keep a journal. Document everything.
- Some regions hold secrets.
- Pay attention to what creatures tell you.

## What you shouldn't know (discover for yourself)

- How many creatures exist in total
- What happens when you find them all
- What waits in The Void
- Why some encounters feel different
- What happens at 10 encounters with the same creature
- Where the meta creature lives
- How many things can merge

## Notes

- This is not just a random generator
- Creatures evolve
- Some things only happen once
- Read the thoughts carefully
- The answer is in the seeing
